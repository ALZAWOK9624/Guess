## Challenges & Learnings

- **PATCH null 覆盖问题重复出现** — Story 2.1 encountered this in HorsesPage, but the same issue recurred in Story 2.3's EditRacePage. Need a shared checklist for PATCH-only-changed-fields pattern
- **Story 2.3 审查量最大** (15 patches) — 比赛创建是最复杂的故事，涉及多个模型和前端页面。未来类似复杂度的故事需要更充分的前期设计
- **前端 vitest 仍未配置** — 从 Epic 1 一直 deferred 到现在。Epic 3 涉及大量前端交互（投票 UI、拖拽排序），缺少自动化测试有风险
- **无障碍模式学习曲线** — `aria-expanded` 硬编码、缺少 `aria-controls`、`aria-labelledby` 等问题在多个故事中重复出现
- **数据库迁移问题** — 004 号迁移的枚举大小写与 SQLAlchemy 默认行为不一致，导致首次部署时出错

## Key Insights

1. **复杂故事需要更充分的设计** — Story 2.3 的 15 个 review patch 说明跨模型的前端+后端故事需要在实现前做更详细的规划
2. **Lessons Learned 的传达需要改进** — PATCH null 问题和 a11y 模式在多个故事中重复出现，说明 lessons 没有有效传递到后续故事
3. **测试基础设施是核心竞争力** — 106 个测试零回归让重构和扩展有信心。前端测试是下一步需要解决的问题
4. **数据库迁移需要 end-to-end 验证** — 迁移文件手动编写容易引入不一致，建议在 CI 中运行迁移验证
