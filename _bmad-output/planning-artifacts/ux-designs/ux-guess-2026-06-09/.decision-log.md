# Decision Log — Guess UX

## 2026-06-09 T15:33 — Initial Discovery

### Design Direction
- **Reference**: JRA (日本中央競馬会) official website jra.jp / japanracing.jp
- **Style**: JRA precision-instrument aesthetic — restrained, authoritative, clean
- **Philosophy**: "Horses are beautiful" (JRA rebrand 1987, GK Graphics). Healthy intellectual sport, not gambling.

### Color System
- **Primary**: Deep racing green (JRA grassland green) — `#1A5632`
- **Accent**: Championship gold — `#B8960C` (for CTA, G1 badges, vote confirmation)
- **Background**: Warm off-white — `#F8FAF7` (JRA-style generous whitespace)
- **Surface**: Pure white `#FFFFFF` with subtle green-gray border `#D4DCD0`
- **Rejected**: ui-ux-pro-max initial recommendation (Retro-Futurism / Team Red #DC2626) — too aggressive for friend-circle private platform

### Typography
- **Heading**: Barlow Condensed (for grade badges, point numbers, race names — sports/athletic feel)
- **Body**: System UI font stack (Chinese-optimized): `-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- **Numbers**: Tabular figures for leaderboard columns — Barlow for Latin numerals
- **Rejected**: Full Japanese font import (Noto Serif JP) — too heavy, Chinese system fonts sufficient for v1

### Form Factor
- **Primary**: Mobile (320px–428px) — core voting flow is phone-first
- **Secondary**: Desktop (1024px+) — admin operations (drag-sort, horse management)
- **Responsive**: Single breakpoint strategy — stack on mobile, sidebar on desktop

### Layout Strategy
- **Grid system**: JRA-style rigid grid, card modules, calendar-like race listing
- **Spacing scale**: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 px
- **Max content width**: `max-w-7xl` (1280px) — wide enough for leaderboard tables, not full-width
- **Single column on mobile**, 2-column sidebar layout on desktop admin

### Concerns Identified
- **Accessibility**: WCAG 2.1 AA minimum — 4.5:1 text contrast, touch targets ≥ 44px
- **Chinese typography**: System fonts only v1, no web font loading for CJK
- **Mobile drag-and-drop**: Touch drag for results entry requires careful touch target sizing
- **Data density**: Leaderboard tables must scroll horizontally on mobile without breaking
- **No dark mode in v1**: Light mode only; dark mode gated by user demand
- **No animations**: Reduced motion by default — JRA aesthetic is static precision, not motion flair
- **Privacy**: Vote details visible to all (by design), but registration gated by invite code
