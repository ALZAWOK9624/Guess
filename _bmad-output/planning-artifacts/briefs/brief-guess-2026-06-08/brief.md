# Product Brief: Guess

## Executive Summary

Guess 是一个面向赛马爱好者圈子的竞猜投票网站。一群朋友长期以来通过腾讯问卷对全球各大赛马比赛进行竞猜，现在需要一个专用平台来替代——让投票更专业、排名更直观、积分更有趣。

核心玩法极简：每场比赛每个用户只选一匹自己认为会赢的马。比赛结束后，管理员录入实际排名，系统自动根据各等级赛事的积分规则结算分数。G1 赛事的末尾惩罚和匹数阈值、2 岁 G1 的免扣分保护——这些朋友们玩了很多年的规则，会原封不动地搬到线上。

技术栈为 Vue3 + FastAPI + PostgreSQL，适配桌面与移动端，目标服务约 100 人的用户群，每年处理 30-100+ 场赛事。

## The Problem

一群热爱赛马的朋友，关注全球各大赛事（日本德比、凯旋门大赛、育马者杯等），长期有竞猜传统。她们的现况是：

- **借用问卷工具投票**：腾讯问卷能收答案，但它不是为竞猜设计的——没有积分结算、没有排名可视化、没有比赛历史回顾。
- **积分全靠人工计算**：G1 的 10-5-3-2-1 正分加末尾扣分、G2 的 5-4-3-2-1 无扣分、不同匹数扣分规则变化……每次都要手动算，繁琐且容易出错。
- **没有社区感**：投票就是填个问卷，看不到朋友的排名、没有竞猜氛围、缺乏归属感。
- **管理混乱**：添加比赛、锁定投票、录入结果——没有统一的管理入口，靠群聊通知协调。

这不是一个需要复杂算法的商业产品问题——它是**一个圈子需要自己的游乐场**的问题。

## The Solution

Guess 是一个极简的赛马竞猜平台，把整个流程搬到 Web 上：

1. **管理员添加比赛**：填写比赛信息、选择参赛马匹、指定比赛等级（G1 / G2·JPN1 / 2岁G1 / 自定义规则）——等级决定积分规则。
2. **用户参与投票**：浏览当前开放的比赛，每场选择一匹自己看好的马。
3. **管理员锁定投票**：在比赛开始前锁定，此后用户不可再投。
4. **管理员录入结果**：通过拖拽排序将马匹按实际名次排列，确认后系统自动为所有投票用户结算积分。结果对全员公开，且随时可修改以防录入错误。
5. **查看积分**：积分表页面展示总排名，用户可以看到自己和朋友的累计积分。

积分规则忠实还原朋友们的长期约定：

**G1：** 第1名+10、第2名+5、第3名+3、第4名+2、第5名+1。末位扣分按参赛匹数：≥8匹时倒数第一-10、倒数第二-5、倒数第三-1；7匹时倒数第一-5、倒数第二-1；6匹时仅倒数第一-1。

**G2 / JPN1：** +5、+4、+3、+2、+1，不扣分。

**2岁G1：** 与 G1 正分规则相同（+10、+5、+3、+2、+1），但不扣分。

**自定义规则：** 管理员可选择自行定义正序积分和末位扣分。

## What Makes This Different

- **不是通用投票工具**——专为赛马竞猜设计，积分规则直接内嵌，用户不碰 Excel、管理员不手算。
- **不是博彩产品**——没有金钱下注，纯粹是朋友间的荣誉积分游戏。规则透明、结果公开、随时可查。
- **拖拽排序录入结果**——管理员的录入操作就是一次直观的「排兵布阵」，而非枯燥的填表。
- **圈子由邀请码守护**——管理员生成邀请码，用户凭码注册，保持私密性和社区感。

## Who This Serves

**普通用户（朋友们）：** 核心需求是快速投票 + 看到排名。操作路径极短——打开、选马、确认，不超过三次点击。积分表和比赛结果页是她们日常最常访问的页面。

**管理员（1-2 人）：** 承担比赛管理职责——创建比赛、维护马匹列表、锁定投票、录入结果、生成邀请码。需要一个集中的管理后台，操作高效、容错性强（结果可修改）。

## Success Criteria

- 用户平均在 **30 秒内完成一次投票**
- 管理员能在 **2 分钟内完成一场比赛的创建**
- 一场比赛结果录入后，**积分在确认后即时同步更新**，无需手动触发
- 积分计算 **零差异**：系统自动计算结果与人工按规则计算完全一致
- **前 10 场赛事后**，几乎所有参与问卷竞猜的朋友迁移到 Guess
- 系统在 **100 用户、50+ 场比赛**的数据量下响应流畅

## Scope

### In Scope（首版）

- 邀请制注册与登录（管理员生成邀请码，用户凭码注册）
- 比赛管理：创建比赛、填写马匹、选择等级规则（含自定义）、编辑、删除
- 投票：用户选择一场开放比赛的一匹马，提交后不可修改（锁定前）
- 投票锁定：管理员手动锁定单场比赛的投票通道
- 结果录入：拖拽排序马匹，确认后自动结算积分
- 结果修改：已录入的结果可随时修改，修改后重算积分
- 积分表：全局排行榜，展示所有用户的累计积分
- 比赛等级规则引擎：G1（含匹数分档扣分）、G2/JPN1、2岁G1、自定义
- 响应式 UI：桌面 + 移动端浏览器均可使用
- 比赛结果与投票记录公开可查

### Out of Scope（首版）

- 实时竞猜（比赛过程中动态赔率）
- 金钱下注或虚拟币系统
- 社交功能（评论、互动、个人头像）
- 微信/第三方 OAuth 登录
- 外部赛马数据 API 对接（比赛信息由管理员手动录入）
- 消息推送/通知
- 多语言（仅中文）

## Vision

如果 Guess 被朋友们用起来——

第一年让它跑稳：覆盖所有赛事日程，积分规则无差错，投票流程零摩擦。

然后它可以自然地生长：历史战绩页（每个人的年度投票胜率）、投票统计热力图（谁是大热门）。

更深一步，它可以成为一个圈子共享的「赛马日历」——标注全球赛事日程，自动提醒大家投票，把「一群朋友看赛马猜冠军」这件事变得像呼吸一样自然。
